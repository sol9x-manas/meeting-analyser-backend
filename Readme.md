
# sol9x-meeting-analyser-backend

A meeting analysis backend service built with **TypeScript** and **Express**.

## Tech Stack

- **TypeScript** - Type-safe JavaScript
- **Express** - Web framework

## DEV Stack
- **Nodemon** - Easy Development

## Getting Started

### Prerequisites

- Node.js (v14+)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
src/
├── routes/
├── controllers/
├── middleware/
└── index.ts
```
